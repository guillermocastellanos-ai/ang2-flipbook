# Ang-2 Masterclass · DMAEn

Visor interactivo de 43 diapositivas, con navegación, índice por temas, miniaturas, búsqueda, zoom y descarga del PDF original.

## Uso

Abre `index.html` en un navegador moderno. Todos los recursos están incluidos y funciona sin conexión.

## Publicación

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

## Dependencias

Incluye PDF.js 5.6.205, distribuido bajo Apache License 2.0. Consulta `THIRD_PARTY_LICENSES.txt`.
