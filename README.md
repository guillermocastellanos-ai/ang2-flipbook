# Biblioteca de materiales DMAEn

Biblioteca interactiva publicada con GitHub Pages.

- `index.html`: portada para elegir material.
- `ang2.html`: Ang-2 Masterclass, 43 páginas.
- `hsr-2026.html`: HSR 2026 DMAEn, 6 páginas.

Los visores incluyen índice por temas, miniaturas, búsqueda, zoom, descarga del PDF original y tres transiciones: profundidad, pasar página y sin animación. Respetan la proporción de cada página y las preferencias de movimiento reducido del dispositivo.

Los enlaces anteriores a `/#page=N` redirigen a la misma página de Ang-2 Masterclass. El enlace «Materiales» vuelve a la biblioteca.

Cada visor incluye todos sus recursos y puede abrirse sin conexión. Para abrir la biblioteca local, abre `index.html` y mantén los dos visores en la misma carpeta.
