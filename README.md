# Biblioteca de materiales de retina

Biblioteca interactiva publicada con GitHub Pages, con filtros por DMAEn, EMD y OVR.

- `ang2.html`: Ang-2 Masterclass · DMAEn, 43 páginas.
- `hsr-2026.html`: HSR 2026 · DMAEn, 6 páginas.
- `secado-rapido-emd.html`: Secado rápido · EMD, 2 páginas.
- `rhone-x.html`: RHONE-X · EMD, 2 páginas.
- `hafner-ovr.html`: Hafner · OVR, 2 páginas.
- `ang2-emd.html`: Ang-2 Masterclass · EMD, 39 páginas.

`index.html` permite elegir material. Cada visor incluye índice por temas, miniaturas, búsqueda, zoom, descarga del PDF original y tres transiciones: profundidad, pasar página y sin animación. Se conservan las páginas completas, su orden y proporción original. Los dípticos se muestran abiertos, tal como aparecen en los PDF.

Los enlaces anteriores a `/#page=N` siguen abriendo Ang-2 Masterclass DMAEn. El enlace «Materiales» vuelve al índice general. Los visores respetan las preferencias de movimiento reducido del dispositivo.

Cada visor incluye sus recursos y funciona sin conexión. Para abrir la biblioteca local, mantén los HTML en la misma carpeta y abre `index.html`.

PDF.js 5.6.205 y OpenJPEG: consulta `THIRD_PARTY_LICENSES.txt`. Los documentos conservan sus contenidos y avisos originales.
